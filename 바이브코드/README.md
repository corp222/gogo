# 🍞 저랑 성심당 가요! (웹 초대장 프로젝트)

요청하신 **토스(Toss) 금융 스타일의 귀여운 3D 모바일 앱 아이콘**을 생성하고, 투명 배경(RGBA) 처리하여 사이트에 최적화 적용했습니다.

---

## 🎨 3D 에셋 목록 (`images/` 폴더)

1. **성심당 입구 (`entrance_transparent.png`)**: 
   - 聖心堂(SUNGSIMDANG) 간판과 붉은 벽돌, 따뜻한 쇼윈도가 담긴 시그니처 3D 건물 아이콘
2. **롤케익 (`rollcake_transparent.png`)**: 
   - 부드러운 스폰지 케이크와 생크림 소용돌이, 딸기 토핑이 올라간 3D 롤케익
3. **카레고로케 (`croquette_transparent.png`)**: 
   - 바삭한 튀김옷과 속이 꽉 찬 카레 속재료가 돋보이는 3번 빵
4. **소금크루아상 (`croissant_transparent.png`)**: 
   - 노릇노릇 버터 결감과 바다 소금 알갱이가 뿌려진 4번 크루아상
5. **튀김소보로 (`soboro_transparent.png`) (보너스)**: 
   - 성심당의 상징이자 부동의 1위 명물 빵

---

## 🌟 사이트 적용 내용

- **1페이지 (저랑 성심당 가요)**:
  - 성심당 본점 입구 3D 아이콘이 둥실둥실 떠오르는 메인 마스코트로 배치되었습니다.
  - 마우스 커서가 다가오면 '싫어' 버튼이 실시간 감지하여 미끄러지듯 도망칩니다.
  - 도망칠 때마다 버튼과 상단 말풍선 멘트가 순서대로 변경됩니다:
    1. `정말요..?` 🥺
    2. `안돼요!` 🙅‍♀️
    3. `안갈꺼예요?` 😢
    4. `계속 도망가야지` 🏃‍♂️💨
- **2페이지 (날짜, 출발 시간 & 빵 선택)**:
  - **출발 시간 선택지**:
    1. `오전 10:00` - 운동 후 밥까지 먹고 출발
    2. `오후 01:00` - 오전 작업 후 출발
    3. `오후 03:00` - 저녁 먹기 전에 돌아오자
    4. `오후 06:00` - 저녁 먹고 다녀오자
  - 튀김소보로, 카레고로케, 소금크루아상, 롤케익을 직관적인 3D 카드형 체크리스트로 선택할 수 있습니다.
- **3페이지 (신청 확인 티켓)**:
  - 성심당 본점 스탬프와 함께, 선택한 빵들의 3D 미니 뱃지가 탑승권 티켓에 예쁘게 박혀 나옵니다.
  - 화려한 축하 꽃가루 폭죽 효과 연사!
